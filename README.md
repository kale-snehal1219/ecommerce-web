# 🌱 AgroSmart Organic

## 📌 Project Description
AgroSmart Organic is a smart farming platform that helps farmers to buy organic fertilizers and get AI-based crop guidance. The platform provides an easy-to-use interface for managing products and improving farming decisions.

---

## 🚀 Features
- 🛒 Product listing and shopping cart system  
- 🤖 AI chatbot for farming advice  
- 🌾 Crop guide section  
- 🌍 Multi-language support  
- 📦 Organic fertilizer marketplace  

---

## 🛠️ Technologies Used
- Frontend: HTML, CSS, JavaScript  
- Backend: Node.js  
- Database: JSON (products.json)  
- Version Control: GitHub
